# P052 fonts

P052 is the Palatino-style family from URW Core 35, Version 2.00.
These unmodified OpenType files reproduce the original website design preview:

| File | CSS weight | CSS style |
| --- | --- | --- |
| `P052-Roman.otf` | 400 | normal |
| `P052-Italic.otf` | 400 | italic |
| `P052-Bold.otf` | 700 | normal |
| `P052-BoldItalic.otf` | 700 | italic |
